# King 集体虚构游戏 — ABM 传播模拟

本仓库包含《"清醒的共谋"：成年初显期视角下大学生参与King集体虚构游戏的心理分析》论文所使用的模拟代码与可视化代码。

## 文件说明

| 文件 | 功能 |
|------|------|
| `simulation.py` | ABM 传播模拟主程序，基于 BA 无标度网络建模三类智能体的信息传播行为 |
| `plot_simulation.py` | 模拟结果可视化，生成三面板组合图（内容产出量、二次创作率、辟谣目标分布） |

## 运行要求

- Python 3.8+
- `networkx` (≥2.5)
- `matplotlib` (≥3.3)
- `numpy`

安装依赖：

```bash
pip install networkx matplotlib numpy
```

## 使用方法

### 运行模拟

```bash
python simulation.py
```

输出内容包括：三类内容产出统计、二次创作率对比、辟谣针对性分析。

### 生成可视化

```bash
python plot_simulation.py
```

生成 `simulation_results.pdf` 和 `simulation_results.png`。

## 模型参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 网络规模 N | 60 | BA 无标度网络，每新节点连接 3 个已有节点 |
| A 型智能体 | 25 | 清醒创作者，对未标记内容以 40% 概率二次创作 |
| B 型智能体 | 25 | 盲信转发者，以 55% 概率转发任何内容 |
| C 型智能体 | 10 | 辟谣者，对未标记内容以 65% 概率产出辟谣 |
| 模拟轮数 | 12 | 同步传播 |
| 随机种子 | 42 | 结果可复现 |
